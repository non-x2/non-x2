## 🚦 いちばん大事な設計方針：**タイトルと違う数字を出す**

公開済み2本のサムネは「**上段＝状況フリ → 中段＝大きな数字 → 下段＝テーマ**」の3段構成です（[型の実デザイン記録](../../templates/04_サムネイル設計.md)）。今回もこれを踏襲します。

**ただし1点だけ意識してほしいこと**があります。

- タイトルのフックは「**3日もちません**」
- ここでサムネの中段にも「3日」と書くと、**同じことを2回言うだけ**になります
- サムネに**別の数字**を置けば、**タイトルとサムネで2つの驚き**を届けられます

→ そこで中段は、リサーチでいちばん強かった**トイレの数字**にします。

---

## 🅰 サムネコピー3案

> 1行あたり13文字前後・最大3行。実チャンネルは「行分けで整理されていれば多めでも成立」と実測済みなので、3段構成なら詰めても大丈夫です。

| 案 | 上段（状況フリ） | 中段（**大きな数字**） | 下段（テーマ） | 想定クリック理由 |
|----|----------------|---------------------|--------------|----------------|
| **A** ⭐ | 水も食料もあるのに | **トイレ 0個** | 買ってはいけない防災グッズ5選 | 「うち、たしかに0個だ」と**自分ごと**になる |
| B | 4人家族に必要な | **携帯トイレ 140個** | 買ってはいけない防災グッズ5選 | 数の多さで驚かせる。ただし**140という数の意味が一瞬で伝わりにくい** |
| C | いざ停電… | **3日もちません** | 買ってはいけない防災グッズ5選 | 分かりやすいが**タイトルと丸かぶり**。情報が増えない |

**採用案：A**

**理由**：
1. **タイトル（3日もちません）と重複しない** → タイトル＋サムネで2つのフックになる
2. 「**0個**」は数字として最短・最大インパクト。スマホの小さい表示でも一瞬で読める
3. 「水も食料もあるのに」＝**備えている人ほど刺さる**（この動画のターゲットは「何か買わなきゃ」と思っている人）
4. 動画の山場（容疑者④）と**中身が一致**している＝クリックベイトにならない

> ⚠️ **「0個」の正確さについて**：台本の④で、ずんだもんが「（家に）**ゼロなのだ**」と言う場面がそのままあります。
> 誇張ではなく**動画内で実際に扱う内容**なので、クリックベイトにはあたりません。

## 🎨 ビジュアル要素（AI生成画像を活用）

| 要素 | 指定 |
|------|------|
| **背景** | **濃紺〜黒のグラデーション**（公開済み2本と同じ。文字が最大コントラストで浮く） |
| **メイン被写体** | 中央〜右寄りに「**空っぽの棚／水と食料だけが並んだ棚**」。**トイレの場所だけぽっかり空いている**のが分かる絵 |
| **キャラ立ち絵** | **左に四国めたん（腕組み・きびしい表情）／右下にずんだもん（驚いた表情）**。※実サムネは左右配置。キャラがチャンネルの顔 |
| **配色（3色）** | **黒（背景）× 赤（帯）× 黄（数字）**。公開済み2本と統一 |
| **文字色・縁取り** | 上段＝白文字＋黒縁／中段＝**黄色文字＋太い黒縁**（赤帯の上）／下段＝白文字＋黒縁 |
| **強調** | 中段「**トイレ 0個**」を**赤い帯**の上に大きく。「0」だけさらに一回り大きく |
| **矢印・囲み・バツ印** | 棚の空いている場所に**赤い×印**または**赤い点線の枠**（「ここが無い」を一目で） |
| **ロゴ** | 右下に「選び方特捜部」を**黄色の小さめ文字**（公開済みのモバイルバッテリー版と同じ位置） |

### 🤖 AI画像の生成プロンプトメモ（日本語→英語に訳して使う想定）

```
防災用の棚の写真風イラスト。暗い部屋。棚には
・水のペットボトルの箱
・缶詰やレトルト食品
・懐中電灯
が整然と並んでいる。棚の一段だけが完全に空っぽで、
そこにだけ光が当たっていない。
写実寄り・暗いトーン・中央やや右に配置・上下に文字を入れる余白を大きく空ける。
文字は入れないこと。
```

> 💡 **文字はAIに描かせない**こと。AI生成の日本語は崩れます。**文字は編集ソフトで載せてください**。

## 🧪 ABテスト案（YouTubeのサムネテスト機能を使う場合）

| | パターン1 | パターン2 |
|---|---|---|
| コピー | **A（トイレ 0個）** | **B（携帯トイレ 140個）** |
| ビジュアル | 空っぽの棚 | 携帯トイレを積み上げた山 |
| 仮説 | 「**足りない（0）**」と「**多すぎる（140）**」、**どちらの見せ方がクリックされるか** |

> 📌 この比較は**次の1本にも効く知見**になります。うちのチャンネルはまだサムネの傾向データが無いので、
> 「不足を突く」か「量で驚かせる」かを1回はっきりさせておく価値があります。

## ✅ サムネ チェック

- [ ] **スマホの小さい表示でも「トイレ 0個」が読める**（いちばん大事。実機で確認）
- [ ] 3秒で「防災グッズの選び方の話」だと分かる
- [ ] タイトルと内容が一致している（クリックベイトでない）
- [ ] **タイトルの「3日」とサムネの数字がかぶっていない**
- [ ] 同ジャンルの並び（防災系は9月に激増します）で埋もれない配色・コントラスト
- [ ] 3段の行分けが整理されていて、詰め込みすぎに見えない
- [ ] AI生成画像に不自然な破綻（指／文字崩れ／棚のゆがみ）がない
- [ ] **キャラ立ち絵が入っている**（チャンネルの顔）
- [ ] 右下に「選び方特捜部」のロゴが入っている

## ⚠️ 9月の防災シーズン特有の注意

9月1日の防災の日に向けて、**8月末は防災動画がいっせいに増えます**。並んだときに埋もれないために：

- **背景の黒**は他の防災動画（明るい・青系が多い）と差がつくので、**そのまま活かす**
- **「0個」の黄色**は、赤やオレンジが多い防災系のサムネの中で目立ちます
- 逆に**避けたいのは**：非常持ち出し袋の写真をそのまま大きく置くこと（**他と同じ絵**になります）
