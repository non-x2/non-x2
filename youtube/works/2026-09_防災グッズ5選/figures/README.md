## 🔥 いちばん大事な使い方：`01a` → `01b` を**続けて切り替える**

この2枚は、**同じ場所・同じ大きさ**でトイレの袋を並べてあります。
`01a`（3行）から `01b`（7行）に切り替えると、**山が下から上へ育つ**ように見えます。

台本（③-4）のこの流れに合わせてください：

| セリフ | 出す画像 |
|---|---|
| ずんだもん「5個 × 3日 × 4人＝**ろくじゅっこ**なのだ！」 | **`01a`** |
| めたん「**60個。しかもそれ、"最低限"よ。**」 | `01a` のまま |
| めたん「『**1週間分の備蓄がおすすめです**』——つまり、」 | （ためる） |
| ずんだもん「**ひゃくよんじゅっこ**なのだーっ！！」 | **`01b` に切り替え** |

> 💡 1枚で140個をいきなり見せると、驚きが1回で終わります。**2段階**が効きます。

## 🛠 作りなおしたいとき

文字や数字を直したくなったら、`generate.js` の中の文章を書きかえて、下のコマンドを実行します。

```bash
node youtube/works/2026-09_防災グッズ5選/figures/generate.js
```

- 必要なもの：Node.js と Playwright（**クラウドのClaudeの部屋には最初から入っています**。ローカルで動かすなら `npm i -g playwright` が要ります）
- 実行すると、このフォルダの7枚が**上書き**されます
- 作りなおした直後のファイルは少し大きくなります（1枚500KB前後）。気になる場合はそのままで問題ありません（見た目は同じです）

> 💡 **のんさんがご自分で直す場合**：`generate.js` をメモ帳などで開いて、
> `"..."` で囲まれた**日本語の部分だけ**を書きかえるのが安全です。記号や `<div ...>` は触らないでください。
