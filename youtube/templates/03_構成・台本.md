# 03. 構成・台本 ★中核

> 「選び方特捜部」型の**黄金構成（取り調べフォーマット）**を穴埋めするテンプレ。各ブロックに
> **掛け合いセリフ(VOICEVOX用)／テロップ／AI画像・図解の指示／想定秒数**を埋めれば、そのまま制作できる台本になります。
> トーン・制作前提（ずんだもん×四国めたんの掛け合い／AI画像／容疑者3〜5人）は [../00_スタイルガイド.md](../00_スタイルガイド.md)、引き出しは [../library/](../library/) を参照。

| 項目 | 内容 |
|------|------|
| タイトル | 　 |
| 階級 | □ 本編（10分前後・容疑者5人前後） / □ ミニ解説（2〜3分・容疑者3人） |
| 想定尺合計 | 　分　秒（目安＝冒頭45秒＋容疑者数×1分30秒＋まとめ1分15秒） |
| 結論（1行） | 　 |
| 免責が必要なテーマ？ | □ はい（水回り/電気/農業など）→ ⑤で動画内免責を必須 / □ いいえ |

> 📱 **ショート（30秒）は別枠**：フック→いちばん重要な容疑者1人→CTA、の3ブロックだけで作る（このテンプレの①と③を1つずつ使う）。

## 🏗 構成サマリー（先に全体像を固める）

| # | ブロック | 役割 | 目安秒数（実測ベース） |
|---|---------|------|---------|
| ① | フック | 悩み・危険の提示＋「容疑者◯人を取り調べ」予告 | 0:00–0:25 |
| ② | 導入 | チャンネル紹介＋今日の容疑者一覧 | **20秒以内**（本題まで45秒以内が目標） |
| ③ | 取り調べ×3〜5 | 容疑者1人ずつ：何者か→容疑→検証→**判決（シロ/クロ）** | 1人あたり 本編≈1:30／ミニ≈0:45 |
| ④ | （任意）じゃあどれを選ぶ？ | シロの中からタイプ別おすすめ2〜4点 | 必要なときだけ |
| ⑤ | ⚠️ 注意（免責） | 専門家相談・有資格者へ | 該当テーマは必須 |
| ⑥ | まとめ＋CTA | **判決一覧**の復習＋「次の捜査にも"出動"してね」 | 約1:15 |

> 🎙 台本は **ずんだもん×四国めたんの掛け合い** 前提。**セリフには話者名を明記**する（例：「ず＝ずんだもん／め＝めたん」と略記を決める）。
> 一文は短く、難読語に読み注記、数字・型番の読み方を明記（ルールは [../00_スタイルガイド.md](../00_スタイルガイド.md)）。

## ② 導入（〜0:45）

> チャンネル紹介＋容疑者一覧を**20秒以内**で。⚠️ 実測では導入48秒が離脱しやすい区間だったため短縮（ミニ解説の「22秒で本題」が手本）。

- **掛け合い**：（例：め「“どれを選べばいい？”を取り調べで解決する、選び方特捜部よ」／ず「今日の容疑者は◯◯たち、全部で◯人なのだ」）
- **テロップ**：（例：今日の容疑者 ①〜⑤）
- **AI画像・図解**：（チャンネルロゴ／容疑者一覧図）
- **想定秒数**：　秒
