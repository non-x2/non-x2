## ✅ サムネ チェック

- [ ] スマホの小さい表示でも文字が読める
- [ ] 3秒で「何のジャンルの選び方か」が分かる
- [ ] タイトルと内容が一致している（クリックベイトでない）
- [ ] 同ジャンルの並びで埋もれない配色・コントラスト
- [ ] 文字量は詰め込みすぎていない（13文字×2行以内目安）
- [ ] AI生成画像に不自然な破綻（指/文字崩れ等）がない

## 📼 実デザイン記録（2026-07-19 実サムネ分析）

公開済みサムネ2枚（除湿機・モバイルバッテリー）から確認できた**現在の型**。新作はまずこれを踏襲し、ABテストで崩していくのがおすすめ：

| 要素 | 実際のデザイン |
|------|--------------|
| 背景 | **濃紺〜黒系の暗い単色/グラデ**（文字が最大コントラストで浮く） |
| キャラ | **ずんだもん・四国めたんの立ち絵**を左右に配置（🔍の代わりにキャラがチャンネルの顔） |
| 強調色 | **赤い帯・バッジ＋黄色文字**で数字・危険ワードを強調（例：「電気代2倍」「実は6〜7割⁉️」） |
| 文字構成 | 上段=状況フリ（例：夏にコレ買うと）→ 中段=**大きな数字インパクト** → 下段=テーマ（例：買ってはいけない除湿機5選）の3段構成 |
| 文字量 | 13文字×2行の目安より**多め**でも成立（行分けで整理されているため） |
| ロゴ | 「選び方特捜部」を黄色の小さめ文字で右下に配置（モバブ版で確認） |
