# 🌀 台風情報まとめ

台風が近づいてきたときに、スマホでサッと開いて使う防災ページです。
HTMLファイル1つだけでできていて、`index.html` をブラウザで開けばそのまま動きます。
サーバーの用意も、インストールも要りません。

## 中身（3つのタブ）

| タブ | 何が見られるか |
|---|---|
| 📡 リンク集・備え | 気象庁・NHKなど公式サイトへのリンク、避難を判断するときのリンク、台風が来る前の準備チェックリスト、台風の豆知識 |
| 📝 今の状況 | 発生中の台風、これからどうなるかの予想（時系列）、すでに過ぎた台風 |
| 🗺️ マップ | 台風がどのあたりを通るかの模式図 |

## 特徴

- **チェックリストが保存される** — チェックを入れた状態は端末に残るので、台風前に何度開き直しても消えません
- **情報の古さを自動で表示** — 「3日前の情報です」のように出ます。古すぎるときは警告が強くなります
- **明るい画面・暗い画面のどちらにも対応** — 端末の設定に自動で合わせます
- **アニメーションを控える設定にも対応** — 端末で動きを減らす設定にしている場合は、動きが止まります

## ⚠️ 大事な注意

**このページは自動で更新されません。**

気象庁などから自動でデータを取ってくる仕組みは入っていません。載っている台風の情報は、
更新した時点で人が調べて書き込んだ「スナップショット（そのときの写し）」です。

地図も実際の観測データではなく、**だいたいの位置関係をつかむための模式図**です。

👉 **実際の避難の判断は、必ず気象庁とお住まいの自治体の最新の発表に従ってください。**
ページ内の各所から公式サイトへのリンクを用意してあります。

## 更新のしかた

内容を新しくしたいときは、Claude に「最新にして」と伝えてください。
そのときのニュースを調べ直して、ページに反映します。

更新した場合は、ページ冒頭の `<time datetime="...">` の日付も一緒に直してください。
この日付をもとに「◯日前の情報です」の表示が計算されています。

## 公開するには

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で
Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にしてください。
公開後は次のURLで開けます。

```
https://non-x2.github.io/non-x2/typhoon-app/
```
