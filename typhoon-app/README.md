# 🌀 台風情報まとめ

台風が近づいてきたときに、スマホでサッと開いて使う防災ページです。
HTMLファイル1つだけでできていて、`index.html` をブラウザで開けばそのまま動きます。
サーバーの用意も、インストールも要りません。

## 中身（4つのタブ）

| タブ | 何が見られるか |
|---|---|
| 📡 リンク集・備え | 気象庁・NHKなど公式サイトへのリンク、避難を判断するときのリンク、台風が来る前の準備チェックリスト、台風の豆知識 |
| 📝 今の状況 | 発生中の台風、これからどうなるかの予想（時系列）、すでに過ぎた台風 |
| ⚠️ 警報・注意報 | いま全国のどこに、台風に関係する警報・注意報が出ているか（くわしくは下の「⚠️ 警報・注意報タブのしくみ」） |
| 🗺️ マップ | 台風がどこを通ってきて、これからどこへ進むか |

## ⚡ 自動で新しくなります

**Claude を開かなくても、ページの中身は勝手に新しくなります。**
気象庁が公開している公式データを読みに行くしくみが入っているためです。

新しくなるルートは4つあり、上から順に試して、**ダメでも必ず次が出る**ようになっています。

| # | ルート | いつ使われるか | 新しさ |
|---|--------|--------------|--------|
| ① | **ブラウザから気象庁へ直接** | ページを開いたとき毎回 | 開いた瞬間の最新 |
| ② | `data/latest.json`（控え） | ①がつながらないとき | 最大1時間前 |
| ③ | **端末に残った前回のデータ** | 圏外などで①②どちらもダメなとき | 最後に見られた時点 |
| ④ | ページに書いてある文章 | ①〜③ぜんぶダメなとき | 人が最後に書いた時点 |

①②で読み込めたときは、画面の上のバッジが **⚡ 気象庁の発表：◯月◯日◯時** という緑の表示に変わります。
③のときは「⚠️ 前回のデータを表示しています」という注意書きが付きます。
オレンジの「⚠️ これはスナップショットです」が出ているときは④、つまり自動取得ができなかったときです。

また、**開きっぱなしでも30分ごとに自動で取り直します**。別のアプリから戻ってきたとき（10分以上経過）にも取り直すほか、ヘッダーの **「🔄 いま更新する」ボタン**でいつでも手動更新できます。

### ②の控えデータを作っているもの

- **しくみ**：`.github/workflows/typhoon-update.yml`（GitHub Actions）
- **頻度**：1時間ごと（毎時25分）
- **やること**：`typhoon-app/scripts/fetch_typhoon.py` を動かして `data/latest.json` を書き換える
  （**台風の情報と、警報・注意報の一覧の両方**を保存します）
- **発表内容に変わりがない回はコミットしません**（履歴が無駄に増えないように）
- **今すぐ動かしたいとき**：GitHubの Actions タブ →「🌀 台風情報の自動更新」→「Run workflow」

手元で試すこともできます（追加のインストールは不要です）。

```bash
python3 typhoon-app/scripts/fetch_typhoon.py
```

> 🛡 **安全装置**：気象庁から1個でも取れなかったときは、ファイルを**書き換えません**。
> 通信が一瞬切れただけで「台風はありません」と上書きされると危ないためです。

### 🌐 インターネットへの公開も自動です

公開URL： https://non-x2.github.io/non-x2/typhoon-app/

**設定画面を開いてオンにする作業は要りません。** `.github/workflows/pages-deploy.yml` が、
GitHub Pages が**まだオフなら自動でオンにして**、そのまま公開します。

- **いつ公開しなおすか**：`main` が新しくなったとき／台風データの自動更新が終わったとき／手動ボタン
- **公開するもの**：🔒 **入口ページ（`index.html`）と `typhoon-app/` だけ**。
  作業ログ・脚本・YouTubeの型などはGitHub上に置いたままで、ホームページとしては公開しません
  （検索に載る範囲を必要最小限にするためです）

> 定期実行（毎時25分）は **`main` に入ってから**動きます。GitHubの仕様で、予約実行は既定のブランチのものだけが動くためです。

> 💤 **60日ルール**：リポジトリに60日間なにも動きがないと、GitHubが定期実行を自動で止めます。
> 止まったらメールが届くので、Actions タブから「Enable workflow」を押せば再開します。
> （①のブラウザ直接取得は、これとは関係なく動き続けます）

📗 詳しい確認のしかた・困ったときの対処 → [`../docs/手順書_台風ページの公開と自動更新.md`](../docs/手順書_台風ページの公開と自動更新.md)

## ⚠️ 警報・注意報タブのしくみ

**台風のときに気をつける5種類だけ**を表示します。

| 種類 | 出るもの |
|---|---|
| 💨 暴風 | 暴風特別警報／暴風警報／**強風注意報** |
| 🌊 波浪 | 波浪特別警報／波浪警報／波浪注意報 |
| 🌊 高潮 | 高潮特別警報／高潮警報／高潮注意報 |
| ☔ 大雨 | 大雨特別警報／大雨警報／大雨注意報 |
| 💧 洪水 | 洪水警報／洪水注意報（洪水に特別警報はありません） |

> 「暴風」の**注意報だけ**は、気象庁の決まりで **「強風注意報」** という名前で出ます。名前が違うだけで、暴風の注意報のことです。
> 雷・乾燥・濃霧といった、台風と関係のないふだんの注意報は**扱いません**（そちらは防災ページ [`../bousai-app/`](../bousai-app/) の担当です）。

- 全国 **58の予報区**（都府県など）をひとつずつ確認し、**出ている所だけ**を一覧にします
- 重い順に **🟣 特別警報 → 🔴 警報 → 🟡 注意報** でグループ分けして並べます
- 何も出ていないときは「✅ いま、台風に関係する警報・注意報は出ていません」と表示します
- **警報以上が出ているときは、タブの見出しが「⚠️ 警報・注意報 🔴」に変わります**（他のタブを見ていても気づけるように）

> 🏙 **ここに出るのは「予報区」＝都府県などの大きなくくりです。**
> 「東京都」と出ていても、実際に出ているのは伊豆諸島だけ、ということがあります。
> **市町村ごとの細かい情報は、必ず気象庁のページで確認してください。**

### 通信を2段階に分けています

58予報区ぶんをまとめて読むと、1予報区あたり約14KB×58で **合計およそ800KB**。
台風のときのスマホで毎回これを読むのは重いので、こう分けています。

| いつ | どこから読むか | 通信の回数 |
|---|---|---|
| ページを開いた直後 | ②`data/latest.json`（控え）だけ | 1回（軽い） |
| ⚠️タブを開いたとき | ①気象庁から直接 | 58回（いちばん新しい） |
| 「🔄 いま更新する」を押したとき | ①気象庁から直接 | 58回 |

「開くだけの人」には軽く、「実際に警報を見たい人」には最新が届くようにするためです。
⚠️タブを開き直しても、**10分以内に気象庁から取れていれば取り直しません**（通信の無駄づかいを防ぐため）。

> 🛡 **安全装置**：気象庁から読むとき、**58のうち1つでも失敗したら全部やめて、控えのデータに切り替えます。**
> 一部だけ取れた状態で一覧にすると、本当は警報が出ている県を「警報なし」と表示してしまい、かえって危ないためです。
> 控えも読めないときは、案内文と気象庁へのリンクだけを出します。

## そのほかの特徴

- **チェックリストが保存される** — チェックを入れた状態は端末に残るので、台風前に何度開き直しても消えません
- **情報の古さを自動で表示** — 「3時間前」のように出ます。古すぎるときは警告が強くなります
- **明るい画面・暗い画面のどちらにも対応** — 端末の設定に自動で合わせます
- **アニメーションを控える設定にも対応** — 端末で動きを減らす設定にしている場合は、動きが止まります
- **どこで見ても日本時間** — 海外から開いても時刻は日本時間で表示されます

## ⚠️ 大事な注意

自動で新しくなるようになりましたが、**このページは気象庁の代わりにはなりません。**

- 地図は気象庁の発表値をもとに、このページが**独自に描いた簡易図**です
- 「◯◯からおよそ◯◯km」という距離は、台風の中心からの**おおよその直線距離**です
- 暴風域に入るかどうかの正式な判断は、**気象庁の警報・注意報**が基準です

👉 **実際の避難の判断は、必ず気象庁とお住まいの自治体の最新の発表に従ってください。**
ページ内の各所から公式サイトへのリンクを用意してあります。

## ④の文章（スナップショット）を書き直したいとき

①②が動かなかったときに出る予備の文章です。ふだんは触らなくて構いません。
書き直したいときは Claude に「台風情報まとめの予備の文章を更新して」と伝えてください。
そのとき、ページ冒頭の `<time datetime="...">` の日付も一緒に直します。

## ファイル構成

```
typhoon-app/
├── index.html                  # ページ本体（これ1枚で動く）
├── data/latest.json            # ②の控えデータ（台風＋警報・注意報。GitHub Actionsが自動更新）
├── scripts/fetch_typhoon.py    # 気象庁からデータを取ってくる部品
└── README.md                   # このファイル
```

データの出どころ：[気象庁 台風情報](https://www.jma.go.jp/bosai/typhoon/)
