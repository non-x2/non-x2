# 2. 防災情報まとめ（地震・津波・雷・大雨）を新規作成

> 💡 上の「次にやるなら（持ち越し）」に挙がっていた
> 「気象庁の**警報・注意報**も自動で読み込んで表示する」が、この作業で実現しました。

## やったこと（結論ファースト）

のんさんの依頼「**地震、津浪、落雷、大雨情報を作って**」を受けて、
台風ページの弟分 **`bousai-app/`（防災情報まとめ）** を新規作成した。

- 公開URL（マージ後に有効）：https://non-x2.github.io/non-x2/bousai-app/
- 4タブ構成：🌏地震（最近の地震一覧）／🌊津波（警報・注意報のいま）／⚡雷（雷注意報の全国一覧）／☔大雨（大雨・洪水の警報注意報の全国一覧）
- 台風ページと同じ**4段構え**：①ブラウザから気象庁へ直接 → ②`data/latest.json`（GitHub Actionsが毎時35分更新）→ ③端末に残った前回分 → ④案内文＋公式リンク
- ①は10分ごと自動で取り直し＋「🔄 いま更新する」ボタンつき
- 4つの話題は**別々に**フォールバックする（地震だけ①で雷は②、もあり得る）

## 作った・変えたファイル

| ファイル | 内容 |
|---------|------|
| `bousai-app/index.html` | ページ本体（新規。1枚もの・外部ライブラリなし） |
| `bousai-app/scripts/fetch_bousai.py` | 気象庁からデータを取って `data/latest.json` を作る係（新規・Python標準機能のみ） |
| `bousai-app/data/latest.json` | ②の控えデータ（最初は仮ファイル。Actionsが本物に置き換える） |
| `bousai-app/README.md` | 説明書（新規） |
| `.github/workflows/bousai-update.yml` | 毎時35分の自動更新（新規。台風の毎時25分とずらした） |
| `.github/workflows/pages-deploy.yml` | 公開対象に `bousai-app/` を追加＋防災更新の完了後も公開しなおす |
| `index.html`（入口ページ） | 防災ページへのカードを追加 |
| `CLAUDE.md` | 進行中プロジェクトに追記 |

## 引き継いだ安全装置（トラブル解決記録の教訓）

- **T12**：地震・津波・警報のうち**1種類でも取得に失敗したら `latest.json` を書き換えない**（間違った「何もありません」を出さない）
- **T13**：Claudeがボタンを押さなくても動くよう、きっかけは schedule／workflow_dispatch／（公開は）workflow_run
- **T14**：外から届くデータは「いつもの形」で来ない前提。津波は自動判定できないとき**「確認できませんでした」と正直に表示**して公式リンクへ誘導
- **T11**：見た目は**画像にして目で確認**してから報告（試験データを差し込んだテスト用コピーで4タブぶん確認済み）
