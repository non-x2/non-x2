## 🖥 ローカル環境との連携プラン（提案）

**考え方：「書く系＝クラウド、動かす系＝ローカル」。連携のハブはGitHub。**

| 作業 | 向いている環境 | 理由 |
|------|--------------|------|
| 台本・企画・脚本づくり、リポジトリ整理、PR作成、Web調査 | ☁️ クラウド（claude.ai/code） | スマホからでも指示でき、任せて待てる |
| VOICEVOX収録・動画編集・YouTube Studioへのアップロード | 💻 ローカル | 音声/動画ソフトはPCにしかない |
| `typhoon-app/index.html` をブラウザで開いて使う | 💻 ローカル | HTMLをダブルクリックするだけ |
| `excel-jan-barcode/` のPython実行・バーコード印刷・スキャナー確認 | 💻 ローカル | プリンター・スキャナーが必要 |
| 実動画の「テロップ量・テンポ」確認（チューニング残項目） | 💻 ローカル | 動画の再生・目視が必要 |

**連携のしくみ（すでに動く状態）**
1. クラウドで作った成果物 → PR → squashマージ → ローカルで `git pull origin main` で受け取る
2. ローカルで直したファイル → コミット＆プッシュ → クラウドの次セッションが続きから使える
3. `CLAUDE.md`＋`作業ログ` は**両方の環境でClaudeが自動で読む「共有メモ」**。セッション終わりのログ追記を両環境の習慣にする

**ローカル側の初期セットアップ（未done なら）**
```bash
git clone https://github.com/non-x2/non-x2.git   # 初回のみ
cd non-x2
claude                                            # Claude Code を起動（CLI or デスクトップアプリ）
```
→ 起動すると `CLAUDE.md` を自動で読むので「作業ログの続きから」と言えばOK。
※ ローカルでは `gh` CLI が使える可能性が高い（T7はクラウド側の制約）。
