# 指示書 — 記憶の同期セットアップ（ローカル⇄クラウドで記憶を共有する）

> 💻 PCの中だけにあるローカルClaudeの「個人メモリ」を、リポジトリの **`docs/共有メモリ.md`** に移して、
> ☁️ クラウドのClaudeとも共有できるようにする手順です。
> さらにObsidianの「Git」プラグインを使うと、**PC起動中は自動で同期**され続けます。

> ✅ **2026-08-10 セットアップ実施済み**。ただし実際の形は、この下の設計図と少し違う場所に着地しました。**まず次の「実際はこうなりました」を読んでください。**

## ✅ 実際はこうなりました（2026-08-10 の実施記録）

セットアップ中に2つのことが分かりました：

1. のんさんのPCのClaude作業フォルダ（`C:\AI\Claudo`）は、**のんラボのコピーではない別フォルダ**だった。
2. 個人メモリの中身は**収益目標などビジネスの内側の話**で、公開リポジトリ（のんラボ）に置くと世界中に見えてしまう。

そこで、のんさんの承認のもと、記憶の本体は**非公開リポジトリ**に置く形にしました：

| 項目 | 実際の形 |
|------|---------|
| 記憶の本体 | 🔒 非公開リポ **`non-x2/kioku-sync`** の `docs/共有メモリ.md`（PC側の実体は `C:\AI\Claudo\docs\共有メモリ.md`） |
| 💻 ローカルClaude | 個人メモリ（`~/.claude/CLAUDE.md`）がその実体ファイルを `@取り込み` で読む（置換済み。戻す用バックアップ：`~/.claude/CLAUDE_backup_2026-08-10_共有メモリ移設前.md`） |
| ☁️ クラウドClaude | のんラボの `docs/共有メモリ.md`（公開OKメモ専用の案内板）は毎セッション読む。個人の記憶が必要なときは「**kioku-syncの共有メモリも読んで**」と頼むと非公開リポを読みに行く |
| 同期のしかた | ローカルで記憶が増えたら、ローカルClaudeに「**共有メモリをプッシュして**」と頼む。自動化したい場合は下のステップ2を、保管庫（vault）を**のんラボではなく `C:\AI\Claudo`** にして設定する |

> 💡 この下の「ステップ1・2」は当初の設計図として残してあります。ステップ1は上の形で**完了済み**。
> ステップ2（Obsidian自動同期）は**任意**で、やる場合は保管庫を `C:\AI\Claudo` に読み替えてください
> （そのフォルダのGitは `docs` だけを管理する設定になっているので、他のファイルが勝手に公開される心配はありません）。

## 仕組み（1枚の絵で）

```
💻 ローカルClaude                         ☁️ クラウドClaude
   ~/.claude/CLAUDE.md（個人メモリ）           CLAUDE.md（地図）
   └─ @取り込みで参照 ──┐                      └─ 開始時に読む ──┐
                        ↓                                       ↓
              📄 docs/共有メモリ.md（記憶の本体・リポジトリ内）
                        ↑↓
        🟪 Obsidian Gitプラグインが10分おきに自動プッシュ／プル
                        ↑↓
                    GitHub（main）
```

- **記憶の本体**をリポジトリ内の1ファイルに置き、両方のClaudeがそこを読む、が基本アイデアです。
- 同期はGit経由。Obsidianの「Git」プラグインが自動でやってくれます（PCを起動してObsidianを開いている間だけ）。

## ステップ1：記憶を書き出す（ローカルClaudeに貼り付け）

ローカルのClaude Codeに、これをそのまま貼り付けてください：

```
個人メモリ（~/.claude/CLAUDE.md）の内容のうち、のんラボに関係する記憶を
docs/共有メモリ.md の「📌 覚えておくこと」に箇条書きで移してください。
APIキー・パスワード・個人情報など秘密のものは移さないこと。
移し終えたら、個人メモリ側のその記憶は
「@（このリポジトリの絶対パス）/docs/共有メモリ.md」という取り込み1行に置き換えてください。
最後に claude/kioku-sync ブランチでコミット→プッシュ→ドラフトPRを作ってください。
```

これで、個人メモリは「共有メモリを取り込むだけ」の形になり、記憶の本体がリポジトリに入ります。

> 📖 `@取り込み` はClaude Code公式の機能です（CLAUDE.mdに `@ファイルパス` と書くと、そのファイルを記憶として読み込む）。
> 詳しくは https://code.claude.com/docs/en/memory

## ステップ2：Obsidianで自動同期をオンにする（1回だけ）

前提：のんラボのフォルダをObsidianの保管庫（vault）にしてある（→ [`手順書_Obsidian活用.md`](手順書_Obsidian活用.md)）。

1. Obsidianの「設定」→「コミュニティプラグイン」→「閲覧」で **「Git」**（作者: Vinzent03）を検索してインストール→有効化。
2. プラグイン設定で次の3つを設定：
   - **Auto commit-and-sync interval（自動コミット＆同期の間隔）**：`10`（分）
   - **Auto pull interval（自動プルの間隔）**：`10`（分）
   - **Merge strategy（マージのしかた）**：`Merge`
3. これで**Obsidianを開いている間、10分おきに自動で保存→プッシュ→プル**されます。

> ⚠️ プラグインはバージョンアップで設定名が変わることがあります。うまくいかないときは
> https://github.com/Vinzent03/obsidian-git の最新の説明を見てください。

## できるようになること

| 場面 | 何が起きるか |
|------|-------------|
| 💻 ローカルでセッションを開始した | 開始フックが**自動でGitHubの最新を確認**。安全なとき（mainブランチ・保存忘れなし）は自動で取り込み、そうでないときは「最新にして」と頼む案内を出す |
| 💻 ローカルで記憶が増えた | 共有メモリ.mdに書く → 10分以内に自動でGitHubへ |
| ☁️ クラウドで作業した | クラウドのClaudeも共有メモリを読める・PRで書き足せる |
| 📱 スマホでObsidianを見る | （Obsidian Git はスマホでは不安定なため、スマホはGitHubのサイトで見るのがおすすめ） |

## ⚠️ 気をつけること（正直な注意書き）

1. **publicリポジトリ＝世界に公開**：共有メモリに書いたことは誰でも読めます。**秘密は書かない**（ルールは共有メモリ.mdの冒頭にも書いてあります）。
2. **mainに直接コミットされる**：Obsidian Gitの自動同期は、のんラボの普段のルール（ブランチ→PR）を通らず**mainへ直接**入ります。**共有メモリ.mdなどメモの編集だけの例外**と割り切ってください。アプリや仕組みのファイル（typhoon-app・bousai-app・.github・toolsなど）はObsidianでは編集しないこと。
3. **ぶつかったら（コンフリクト）**：ほぼ起きませんが、もし起きたらObsidianが知らせてくれます。慌てずローカルのClaudeに「コンフリクトを直して」と頼めばOKです。
4. **自動同期はObsidianを開いている間だけ**：PCが起動していてもObsidianが閉じていれば同期されません。
