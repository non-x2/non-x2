# ☁️💻 クラウドとローカルの使い分け

> **結論：迷ったらクラウドでOK。**「実際に動かして目で見る」ときだけローカル。
> つなぎ役はGitHub。どちらで作っても、GitHub経由でもう片方に届きます。
> 最終更新：2026-07-28

---

## そもそも何が違うの？

Claude Code には作業する場所が2つあります。デスクトップアプリは、この**両方への入り口**です。

| | ☁️ クラウド | 💻 ローカル |
|---|---|---|
| どこ | ネット上の作業部屋 | あなたのPCの中のフォルダ |
| 部屋の寿命 | **使い捨て**（しばらくすると消える） | ずっと残る |
| ファイル | **プッシュしないと消える** ⚠️ | そのまま手元に残る |
| スマホから | 見られる・続きを頼める | 見られない |
| 得意なこと | 任せて待つ作業（書く・調べる・整理する） | 実際に動かす・目で見る作業 |

**いちばん大事な違い：クラウドの部屋は使い捨てです。**
作ったものは必ず「コミット → プッシュ → マージ」まで進めてください（`/git-guide` が手伝います）。

## どっちでやる？（早見表）

| やりたいこと | 場所 | なぜ |
|---|---|---|
| 台本・企画・脚本を書く | ☁️ クラウド | 任せて待てる。スマホからも続きを頼める |
| リポジトリの整理・PR作成・調べもの | ☁️ クラウド | ネットもGitHubも使える |
| 🏷 バーコードExcelを作る | ☁️ **クラウドでOK**（2026-07-28〜） | 部品が自動で入るようになった |
| 🌀 台風アプリを開いて使う | 💻 ローカル | HTMLをダブルクリックして見るだけ |
| バーコードを印刷してスキャナーで読む | 💻 ローカル | プリンターとスキャナーが必要 |
| VOICEVOXの収録・動画編集・YouTubeへの投稿 | 💻 ローカル | 音や動画のソフトはPCにしかない |
| 実動画を再生してテロップ量・テンポを見る | 💻 ローカル | 目と耳で確かめる作業 |

> 迷ったときの判断基準：**「画面で見て確かめる／機械につなぐ」ならローカル。それ以外はクラウド。**

## つなぎ方（すでに動いています）

```
   ☁️ クラウドで作る                 💻 ローカルで動かす
        │                                  │
        │ コミット→プッシュ→マージ          │ 直したらプッシュ
        ↓                                  ↓
        └────────►  GitHub（main）  ◄───────┘
                         │
              次のセッションはここから始まる
```

1. **クラウド → 手元へ**：マージしたら、ローカルで `git pull origin main`
   （Claudeに「最新にして」と言うだけでもOK）
2. **手元 → クラウドへ**：ローカルで直したらプッシュ。次のクラウドセッションが続きから使えます
3. **共有メモ**：`CLAUDE.md` と `docs/作業ログ_*.md` は**両方の環境でClaudeが自動で読みます**。
   セッションの終わりに作業ログを書き足すのが、いちばん効く引き継ぎです

---

## クラウドで気をつけること（3つだけ）

1. **プッシュしないと消える** — 部屋は使い捨て。作業の区切りで必ずプッシュ
2. **`gh` コマンドは使えない** — GitHub操作はClaudeが別の道具（MCP）で代わりにやります。頼み方は今までどおり
3. **一部のサイトにつながらない** — 例：Gamma のサイトへは直接行けない（ただしGamma連携ツールは使えるので実害なし）。
   YouTube・気象庁・Googleなどは接続OK（2026-07-19 確認）

## セッションを始めると自動でやってくれること

このリポジトリでは、セッションが始まると次を自動で表示・準備します（`.claude/hooks/session-start.sh`）。

- 📍 今いるブランチ／保存し忘れの有無／直近の作業／最新の作業ログ
- ☁️ クラウドのときは「消えるよ」の注意＋**バーコードツールの部品を自動インストール**
- 💻 ローカルのときは何もインストールしない（あなたのPCの環境を汚さないため）

> 手動で部品を入れたいときは `pip3 install -r excel-jan-barcode/requirements.txt`

## 始め方

### ☁️ クラウド
デスクトップアプリまたは claude.ai/code で、このリポジトリ（`non-x2/non-x2`）を選んで新規セッション。
→ `CLAUDE.md` を自動で読むので「**作業ログの続きから**」と伝えればOK。

### 💻 ローカル
```bash
git clone https://github.com/non-x2/non-x2.git   # 初回だけ
cd non-x2
git pull origin main                              # 2回目以降は最新化
```
デスクトップアプリで、このフォルダを選んで新規セッション。あとはクラウドと同じ頼み方でOKです。
