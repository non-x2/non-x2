# 🌱 自己改良バックログ（アイデア帳＋改良の記録）

> のんラボを毎日すこしずつ良くしていくための「共有の脳」です。
> - **クラウドの毎朝のRoutine「🌱 毎日の自己改良」**（毎朝6時）が、ここを読んで小さな改良を1つ実行し、ドラフトPRを作ります。
> - **ローカル（デスクトップアプリ）でも「/kaizen」と頼めば同じ型で動きます**。
> - やり方の決まりは `.claude/skills/kaizen/SKILL.md` にあります。**マージは必ずのんさんが行います**（自動では反映されません）。
> - 止めたいときは「毎日の自己改良を止めて」とClaudeに頼めばOKです。

## 使い方

- **候補**：これからやりたい改良のリスト。誰でも（どのセッションでも）気づいたら追記してよい。
- **要相談**：勝手にやってはいけないもの。のんさんの判断が出るまで動かさない。
- **改良の記録**：実際にやったことの履歴。毎回1行追記する。
