# 🅰 🌍「世界のライブカメラ」対応の第一歩（ドラフトPR #56）

のんさんの「**世界のライブカメラを全て網羅する事は出来ますか？**」というご質問から始まったセッションです。

### まず正直にお答えしたこと

**「全て網羅」は世界の誰にもできません**（この道のプロの会社でも6.5万〜15万台どまり）。理由は3つ：
①世界には統一の台帳が存在しない ②権利の壁（商用の会社は200以上の機関と個別契約している）
③カメラは毎日増減する。加えて、無断で監視カメラを集める種類のサイト（Insecam系）は
プライバシー侵害のため**のんラボでは絶対に使わない**。

そのうえで参謀提案「**案A（公式サイトのリンク集）＋案B（米国の州を1つ試験取り込み）**」を
のんさんが採用 →「codex・gemini・ローカルLLMを使って定期的に情報収集して」とのご指示で実施しました。

# 🅱 🎬 YouTubeの型を実動画に合わせて全面改訂（PR #57・マージ済み）

7月末から「のんさんの判断待ち」になっていた**型と実動画のズレ**について、
のんさんの「**お任せします**」の指示を受けて方針を決め、実行しました。

## 🎯 決めた方針（案Aを採用）

**「ガイド（型）側を実動画に合わせて改訂する」＋「導入短縮の目安も型に入れる」**

理由：公開済みの実動画3本がすでに「チャンネルの現実」であり、型は次の1本を
作りやすくするための道具だから。動画側を古い型に戻す理由はない。

## 🔁 何がどう変わったか（ズレ5項目＋短縮目標）

| 項目 | 旧（〜08-15） | 新（実動画準拠） |
|------|-------------|----------------|
| ナレーション | VOICEVOX「玄野武宏」ソロ | **ずんだもん×四国めたんの掛け合い**（取り調べ形式） |
| 看板フォーマット | 「3つのポイント」固定 | **容疑者3〜5人**（本編5人前後・ミニ3人）＋**シロ／クロ判決** |
| CTA | 「これ気になってた！」 | 「**次の捜査にも"出動"してね**」（実動画の締めそのまま） |

| アフィリ表記 | 毎回必須 | 現状リンクなし＝表記なしでOK。**貼る場合は必須**（ルール維持） |

容疑者1人あたり本編≈1分30秒・ミニ≈45秒、見積り式＝冒頭45秒＋容疑者数×1分30秒＋まとめ1分15秒。

## 🤔 判断したこと（なぜそうしたか）

- **「3つのポイント」の看板を降ろした**：実動画3本すべてが取り調べ形式で、決め台詞も
  「容疑者」「シロ／クロ判決」。看板は実態に合わせるのが型の役目。
- **記入例は書き換えず「注記」にした**：掛け合い形式の完成台本を想像で書くと
  実動画と違う「うそ見本」になりかねないため。次の1本を作るときに実台本ベースで
  差し替えるのが安全（下の「次にやるなら」参照）。
- **アフィリのルール自体は残した**：現状リンクなしだが、導入したら表記必須
  （収益化の将来に備えて消さない）。
- **数値はすべて2026-07-19の実測に基づく**（フック25秒・導入48秒・容疑者1人1分37秒→
  台本目安1分30秒、ミニ22秒で本題など）。想像の数字は入れていない。
- **クレジットは「VOICEVOX:キャラ名」形式で全員分**（VOICEVOXの利用ルール）＋
  実動画で確認済みの効果音ラボ・いらすとやを追加。
