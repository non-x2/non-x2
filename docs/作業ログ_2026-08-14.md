## 🔑 いちばんの山場：「http:// の写真は https のページに出せない」問題

全国の道路ライブカメラの写真URLは、調べたところ **1,323件すべてが `http://`（暗号化なし）** でした。
のんラボの公開ページは `https://` なので、そのまま貼るとブラウザが**問答無用でブロック**します（混在コンテンツ）。

**解決策**：台帳を作るときに `http://` → `https://` に読み替えて、**1台ずつ実際に開いてみて**画像が返るものだけ記録する。

| | 台数 |
|---|---|
| 全国のカメラ | **1,430台** |
| └ ページ内で映像が見られる（https で開けた） | **1,038台** |
| └ 公式ページを開いて見る（https で開けなかった） | 392台 |

映像を出せない392台も、**灰色の丸**で一覧に残し、押すと公式ページへ案内します（＝存在ごと消さない）。

## 🤔 経緯（なぜその判断をしたか）

- **なぜ台帳をページに埋め込んだか**：`file://`（ダブルクリックで開く）だと別ファイルの読み込みがブラウザに止められるため。`data/livecams.json`（大もと）と埋め込みは**スクリプトが同時に書き換える**のでズレません（`offices.json` と同じ考え方）。
- **なぜ地図を自前で描いたか**：のんラボの他ページと同じ「1枚のHTMLで完結」を守るため。外部ライブラリ（Leaflet等）を入れると公開ページに他人のコードが混ざります。
- **なぜ「リアルタイム渋滞情報」を出さないか**：調べた結果、**無料・鍵不要でブラウザから直接使える全国リアルタイム渋滞APIが見つかりませんでした**。JARTICのオープンデータは月1更新、交通量APIは20分遅れ＋規約同意が必要。そこで「**カメラで実際の道路を見る**」を主役にし、渋滞の全体像は公式サイトへのリンクで案内しています。
- **Valhalla（下道ルート）を試して見送った**：高速をさけるルートならカメラが増えるかと期待して実測しましたが、細い道を選んでしまい **かえって減った**（浜松→静岡 3km圏で 14台→13台、新潟→長岡 7台→3台）ため採用せず。

### 途中で見つけて直した不具合（4件）

1. **「名古屋駅」と入れると千葉県成田市名古屋が選ばれた** — 国土地理院の検索は住所を先に返すため。入れた言葉との一致の仕方で**点数を付けて選び直す**ようにし、あわせて**入力候補（サジェスト）**も追加。
2. **ルート線が地図タイルの下に隠れて見えなかった** — 重なり順を z-index で明示（タイル→線→ピン）。
3. **全体表示のときルートが豆粒になった** — 余白の取りすぎで拡大率が1段階（＝2倍）下がっていた。余白を40px→24pxに。横幅の79〜89%を使うように改善。
4. **ピンの上からドラッグすると地図が動かなかった** — 「少し動いたらドラッグ、動かなければピンを押した」と見分ける方式に変更。あわせて**近すぎるピンを間引く**処理も追加（67個→6個。拡大すると出てくる）。
