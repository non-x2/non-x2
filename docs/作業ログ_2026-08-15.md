## 1️⃣ 📷 ライブカメラ台帳 `livecam-db/` を新設（PR #48）

カメラ情報を `traffic-app` 専用から切り出し、**どのアプリからでも使える台帳**にしました。

| ファイル | 役割 |
|---|---|
| `build.py` | 集める→重複をまとめる→https確認→市区町村を付ける |
| `export.py` | 各アプリに配る（data と index.html の埋め込みを同時更新） |
| `livecam.py` | **使う道具**（近く・ルート沿い・検索。CLIあり） |
| `sources/` | 情報源ごとの読み取り係（**1ファイル足せば増やせる**） |

ページ内で映像が見られるカメラは **1,038台 → 2,615台（約2.5倍）**。

### ⚖️ 取り込みの線引き（いちばん大事な判断）

のんさんから `livecam.asia`（3.6万件）のご提示がありましたが、**取り込みを見送りました**。
2015年から人手で整理された名簿そのものが商品のサイトで、日本の著作権法では選び方・並べ方に
工夫のあるデータベースにも権利が生じうるためです。

そして**同じ物差しを自分にも当てました**。

| 判断 | 情報源 |
|---|---|
| ✅ 取り込む | 国交省系（JICE 道路・河川）＋海上保安庁（**PDL1.0で明確に許可**・出典明記が条件） |
| ❌ 取り込まない | 「無断転載を禁じます」と明記のある自治体（福井・群馬・青森）／NEXCO等 → **リンクで案内** |
| ⏸ 保留 | 富山県（技術的には理想的だが利用条件の記載が見つからず） |

調べた情報源と判断理由は `livecam-db/README.md` に**一覧で記録済み**。同じ調査を繰り返さないためです。

## 3️⃣ 🚀 お任せモードでの一括改良（PR #52・ドラフト）

**Sonnet×2体**の助手に点検を手分けし、**9コミット**を積みました。

### 見つけて直した不具合

**ルート検索のあと「📍現在地」を押すと、押したのと違うカメラが開いていました。**
一覧には「三重県亀山市」と出ているのに、押すと「国道19号 岐阜県多治見市」が開く状態。
地図とカメラ画面だけ入れ替わり、一覧が取り残されていたのが原因です。

### 主な改良

| 改良 | 効果（実測） |
|---|---|
| カメラ一覧を20台ずつ＋「もっと見る」＋路線ごとの区切り | 一覧 **6.9画面 → 2.3画面** |
| よく使うルートをリンクで保存・共有 | URLを開くだけで同じ検索が再現 |
| 読み上げ・キーボード対応 | 6項目すべて合格 |
| 地図に縮尺バー／ピンを32pxに／枠のかたちで種類を区別 | 色だけに頼らない |
| 台帳：通信エラーの取りこぼし修正 | **1台の不調で週1更新が丸ごと止まる**危険を解消 |
| 台帳：安全装置を情報源ごとに | 道路が全滅しても検知できなかった穴を塞いだ |
| 台帳：案内先のドメイン消滅を検知 | **116台ぶん**を検出 |
| 水の上のカメラにも市区町村名 | 3,402 → **3,419台** |

### 調べて「やらなくてよい」と分かったこと

- 九州で映像が出せないのは https の問題ではなく、**元データの写真URL欄にページのURLが入っていて404**だった
- 「映像が見られるカメラだけ」フィルタは、主要ルート3本で「ページのみ」が**0%**のため不要
- 広域探索の速度は実測 **162ms** で問題なし

## ✅ 結論：台風ページに「🌐 3D地球儀」タブを追加しました（5タブに／ドラフトPR）

のんさんの「**台風情報 3D**」のご依頼で実施。参考リンクとして
[earth.nullschool.net](https://earth.nullschool.net/)（回せる地球儀）と
[Ventusky](https://www.ventusky.com/)（なめらかな動き・時間スライダー）をいただいたので、
**その2つの良いところを台風ページに合わせて作りました**。

## 🌐 何ができるようになったか

| できること | 中身 |
|---|---|
| 🖐 **地球が回る** | ドラッグ／指でなぞる。ホイール・ピンチで拡大縮小、ダブルタップ／「⟲」で最初の向きへ |
| ⏱ **時間を動かせる** | つまみで「実況 → 24時間後 → 48時間後 …」と気象庁の予報の時刻ごとに切り替わる。「▶」で自動再生（Ventusky風） |
| 💨 **渦が回る** | 台風のまわりだけ、反時計回り＋中心へ吸い込まれる渦（nullschool風）。**⚠️イメージである旨を画面に明記** |
| ⌨️ **キーボードでも操作** | 矢印キーで回す、`+` `-` で拡大縮小 |
| 🌏 **裏側は見えない** | 正射図法（宇宙から見た見え方）。本物の地球と同じように、裏に回った線は消える |

## 🤔 判断したこと（なぜそうしたか）

- **新しい5つ目のタブにした**（🗺️マップの中で切り替えにしなかった）
  → 平面の地図は今までどおり残るので、**うまく描けない端末でも今までと同じように使える**ため。
- **地図ファイルを増やさなかった**
  - 世界の海岸線 … Natural Earth 1:1000万（🗺️マップと同じ出どころ・パブリックドメイン）を
    間引いて **138KB → 5.7KB の文字列**にしてHTMLに埋め込み
  - 日本の詳しい海岸線 … **🗺️マップのSVGを読み直して使い回し**。
    あちらはメルカトル図法なので、計算を逆にたどって緯度経度に戻している（＝1バイトも増やさずに詳しい日本が描ける）
- **外部の部品（ライブラリ）はゼロ**。Canvasと計算だけで描いている（「1枚のHTMLで開ける」という約束を守るため）
- **風の実況は描かなかった**
  → 地球全体の風のデータは気象庁が公開していないため。**取れないものを取れたように見せない**方針で、
    「暴風域・強風域の大きさに合わせた渦のイメージ」＋注意書き＋気象庁の風の実況マップへのリンク、という形にした。
- **見ていないあいだは絵を止める**（タブを離れる・別アプリへ行く）→ 電池と発熱の節約。
  端末の「動きを減らす」設定にも対応（渦が止まる）。

## 🛡 安全のために触っていないもの

- 警報・注意報の判定ロジック（58予報区・1つでも失敗したら控えに切り替える安全装置）
- 4段構えのフォールバック（①気象庁直→②latest.json→③端末の控え→④手書き文章）
- 自動更新のワークフロー（`typhoon-update.yml` など）
- `scripts/fetch_typhoon.py`

→ **3D地球儀はデータの「表示のしかた」を1つ増やしただけ**で、データの取り方には一切手を入れていません。
