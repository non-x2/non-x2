## 1️⃣ 📷 ライブカメラ台帳 `livecam-db/` を新設（PR #48）

カメラ情報を `traffic-app` 専用から切り出し、**どのアプリからでも使える台帳**にしました。

| ファイル | 役割 |
|---|---|
| `build.py` | 集める→重複をまとめる→https確認→市区町村を付ける |
| `export.py` | 各アプリに配る（data と index.html の埋め込みを同時更新） |
| `livecam.py` | **使う道具**（近く・ルート沿い・検索。CLIあり） |
| `sources/` | 情報源ごとの読み取り係（**1ファイル足せば増やせる**） |

**カメラ 1,430台 → 3,424台**（一般道1,331／高速81／河川1,819／ダム114／海79）。
ページ内で映像が見られるカメラは **1,038台 → 2,615台（約2.5倍）**。

### ⚖️ 取り込みの線引き（いちばん大事な判断）

のんさんから `livecam.asia`（3.6万件）のご提示がありましたが、**取り込みを見送りました**。
2015年から人手で整理された名簿そのものが商品のサイトで、日本の著作権法では選び方・並べ方に
工夫のあるデータベースにも権利が生じうるためです。

そして**同じ物差しを自分にも当てました**。

| 判断 | 情報源 |
|---|---|
| ✅ 取り込む | 国交省系（JICE 道路・河川）＋海上保安庁（**PDL1.0で明確に許可**・出典明記が条件） |
| ❌ 取り込まない | 「無断転載を禁じます」と明記のある自治体（福井・群馬・青森）／NEXCO等 → **リンクで案内** |
| ⏸ 保留 | 富山県（技術的には理想的だが利用条件の記載が見つからず） |

調べた情報源と判断理由は `livecam-db/README.md` に**一覧で記録済み**。同じ調査を繰り返さないためです。

## 2️⃣ 🛣 高速道路（PR #51）

調べたところ**高速道路のカメラは既に81台入っていました**（「道路」に混ざって見分けられない状態）。
種類として切り出し、🛣のしるしと紫の丸で区別できるようにしました。

**NEXCO・首都高・阪神高速は取り込めません。** NEXCO東日本の利用規約に
「他のサイトや印刷媒体に転載したり、商用目的として利用することはできません」と明記されているためです。
代わりに各社の公式サイトへの案内欄を追加しました（6社・到達確認済み）。

## 3️⃣ 🚀 お任せモードでの一括改良（PR #52・ドラフト）

**Sonnet×2体**の助手に点検を手分けし、**9コミット**を積みました。

### 見つけて直した不具合

**ルート検索のあと「📍現在地」を押すと、押したのと違うカメラが開いていました。**
一覧には「三重県亀山市」と出ているのに、押すと「国道19号 岐阜県多治見市」が開く状態。
地図とカメラ画面だけ入れ替わり、一覧が取り残されていたのが原因です。

### 主な改良

| 改良 | 効果（実測） |
|---|---|
| カメラ一覧を20台ずつ＋「もっと見る」＋路線ごとの区切り | 一覧 **6.9画面 → 2.3画面** |
| よく使うルートをリンクで保存・共有 | URLを開くだけで同じ検索が再現 |
| 読み上げ・キーボード対応 | 6項目すべて合格 |
| 地図に縮尺バー／ピンを32pxに／枠のかたちで種類を区別 | 色だけに頼らない |
| 台帳：通信エラーの取りこぼし修正 | **1台の不調で週1更新が丸ごと止まる**危険を解消 |
| 台帳：安全装置を情報源ごとに | 道路が全滅しても検知できなかった穴を塞いだ |
| 台帳：案内先のドメイン消滅を検知 | **116台ぶん**を検出 |
| 水の上のカメラにも市区町村名 | 3,402 → **3,419台** |

### 調べて「やらなくてよい」と分かったこと

- 九州で映像が出せないのは https の問題ではなく、**元データの写真URL欄にページのURLが入っていて404**だった
- 「映像が見られるカメラだけ」フィルタは、主要ルート3本で「ページのみ」が**0%**のため不要
- 広域探索の速度は実測 **162ms** で問題なし
