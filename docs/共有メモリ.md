# 🧠 共有メモリ（ローカルとクラウドのClaudeが共通で覚えておくこと）

> このファイルは「のんさんとClaudeの共有の記憶」です。
> - 💻 ローカルのClaude：個人メモリ（`~/.claude/CLAUDE.md`）の `@取り込み` 行からここを読みます。
> - ☁️ クラウドのClaude：CLAUDE.mdの案内にしたがって、セッション開始時にここを読みます。
> - 同期のしかた → [`指示書_記憶の同期セットアップ.md`](指示書_記憶の同期セットアップ.md)

## 使い方のルール（3つだけ）

1. **秘密は書かない**：このリポジトリはpublicなので、ここに書いた内容は世界中の誰でも読めます。APIキー・パスワード・住所・電話番号・人に見せたくないメモは**絶対に書かない**（そういうものはPCの個人メモリに残す）。
2. **短く保つ**：目安は**30行以内**。長くなったら古いものを消すか、docs/の別ファイルに移す（毎セッション読むので、長いとトークンがもったいない）。
3. **書き方**：1つの記憶＝1行の箇条書き。「いつ・何を」がわかるように。
