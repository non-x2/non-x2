# 指示書 — 外部AI連携セットアップ（ローカルPC専用）

> Claude Codeが「監督」になって、他のAIの道具（Codex・Gemini・Ollama）に相談しながら作業を進めるための準備ガイドです。
> 対象：**のんさんのPC（ローカル）のみ**。クラウドの部屋（Claude Code on the web）では使えません。

---

## 1. そもそも何ができるようになるか（結論ファースト）

準備が終わると、Claudeが**監督**になり、必要に応じて外部のAIに「相談」「レビュー」「下書き」を頼めるようになります。

- 難しいコードの相談 → Codexに聞く
- 長い調べ物・下調べ → Geminiに聞く
- お金をかけずに軽い下書き → Ollamaに頼む

呼び出し方はかんたんです。

- `/ai-rengo` と頼む（道具がそろっているか点呼してくれる）
- 「Codexに聞いて」「Geminiと相談して」と**そのまま日本語で頼むだけ**

⚠️ どのAIに相談しても、**最終的にファイルを直す・保存する・gitで記録するのはClaudeだけ**です。外部AIは「相談相手」であって「作業者」ではありません。

---

## 2. 3つの道具の比較表

| 道具 | コマンド | 作っている会社 | ログイン方法 | 得意なこと | お金 |
|---|---|---|---|---|---|
| OpenAI Codex CLI | `codex` | OpenAI | ChatGPTアカウント | コードの相談・レビュー | 有料プラン（ChatGPT Plus等）が必要になる場合あり |
| Gemini CLI | `gemini` | Google | Googleアカウント | 調べ物・長文の相談 | **無料枠が大きい** |
| Ollama | `ollama` | （オープンソース） | 不要（ログインなし） | 軽い下書き・アイデア出し | **完全無料・ネット不要** |

---

## 3. 入れ方（3〜5手順ずつ）

### 3-1. OpenAI Codex CLI

1. Node.js が入っているか確認する（入っていなければ https://nodejs.org からインストール）。
2. ターミナルで次を実行：
   ```
   npm install -g @openai/codex
   ```
3. ターミナルで `codex` と打つ。
4. 案内にしたがってChatGPTアカウントでログイン。
5. ログインできたら準備完了です。

### 3-2. Gemini CLI

1. Node.js が入っているか確認する（同上）。
2. ターミナルで次を実行：
   ```
   npm install -g @google/gemini-cli
   ```
3. ターミナルで `gemini` と打つ。
4. 案内にしたがってGoogleアカウントでログイン。
5. ログインできたら準備完了です（無料枠で始められます）。

### 3-3. Ollama

1. https://ollama.com を開く。
2. お使いのPC（Windows／Mac）用のインストーラをダウンロードして実行。
3. インストール後、ターミナルで次を実行して小さめのモデルを試す：
   ```
   ollama run gemma3
   ```
4. 初回はモデルのダウンロードが始まります（少し時間がかかります）。
5. ダウンロードが終われば、その場でチャットが始まります。ネットがなくても動きます。

> ⚠️ **各ツールはバージョンアップで手順が変わることがあります。** うまくいかないときは、上の手順にこだわらず**公式サイトの最新手順**を確認してください。

## 4. 役割分担の目安

| 担当 | 役割 |
|---|---|
| **Claude**（監督） | 全体の進行・最終判断・ファイルの編集・git操作。すべての作業のとりまとめ役 |
| **Codex** | コードの相談相手・レビュー |
| **Gemini** | 調べ物・長文の相談 |
| **Ollama** | 無料の下書き係（アイデア出し・軽いたたき台） |

---

## 5. 安全のやくそく（★重要）

> 🔒 ここは必ず守ってください。トラブルの多くは、この約束を破ったときに起きます。

- **APIキーやパスワードは絶対にリポジトリに書かない・コミットしない。** 各道具は自分のPCの中に自分でログイン情報を保存します。
- **外部AIには「相談」だけさせる。** ファイルの変更やgit操作（コミット・プッシュ・マージなど）は必ずClaudeが行い、Claudeが検品してから反映します。
- **個人情報や秘密のメモを外部AIに渡さない。**
- **クラウドの部屋（Claude Code on the web）には、これらの道具は入っていません。** 外部AI連携は**ローカルPCでだけ**使える機能です。クラウドで似たことをしたいときは、代わりに **`/bunsan`**（Claudeの助手に手分けして頼む型）が働きます。

## 7. 動作確認のしかた

ターミナルで、それぞれのバージョンを確認します。

```
codex --version
gemini --version
ollama --version
```

エラーが出なければインストール成功です。

もっと簡単に確認したいときは、Claudeに次のように頼んでください。

> 「/ai-rengo」

Claudeが3つの道具の状態を点呼して、使える状態かどうかまとめて教えてくれます。

---

## まとめ

1. 3つの道具は「相談相手」。作業や保存はすべてClaude（監督）が行う。
2. まずは無料のGemini CLIとOllamaから試すのがおすすめ。
3. 秘密の情報（APIキー・パスワード・個人情報）はリポジトリに書かない・外部AIに渡さない。
4. この連携が使えるのはローカルPCだけ。クラウドでは `/bunsan` を使う。
5. うまくいかないときは、各公式サイトの最新手順を確認する。
