# JANコード バーコード付き商品リスト生成ツール

Excelでバーコード付きの商品リストを作ったのにスキャナーで読み取れない、という問題を
解決するための「とりあえず動く」ツールです。商品名とJANコードのCSVから、
**本物のバーコード画像**を貼り付けたExcel(xlsx)を自動生成します。

## なぜ画像方式にしたか

バーコード作成フォント(いわゆる「ニコちゃん」的なフリーのバーコードフォント/ツール)を
Excelで使う方式は、次の理由でスキャナーが読めなくなることがよくあります。

- **フォント未埋め込み**: 作った人のPCにしか専用フォントが入っておらず、別のPC(印刷担当のPCなど)で開くと普通の数字に戻ってしまい、バーコードとして印刷されない。
- **チェックデジット(検査数字)の計算ミス**: JANコードの最後の1桁は決まった計算式で出す必要があるが、手入力やコピペでズレると、スキャナーがエラーを出して読み取りを拒否する。

このツールは「専用フォントに頼らず、最初から絵(画像)としてバーコードを描いてExcelに貼る」
方式にすることで、上記の問題を構造的に回避しています。どのPCで開いても、どのプリンタで
印刷しても、見た目が変わりません。

## 必要なもの

- Python 3
- 以下のライブラリ(初回のみインストール)

```bash
pip3 install python-barcode openpyxl pillow
```

## 使い方

1. `products.csv` を編集する(商品名とJANコードの2列。JANコードは12桁でも13桁でもOK)

   ```csv
   商品名,JANコード
   剪定バサミ プロ仕様180mm,4901111222236
   培養土 14L(有機配合),450222233334
   ```

   - 12桁で入力した場合 → 13桁目(チェックデジット)を自動計算して補完します。
   - 13桁で入力した場合 → チェックデジットが正しいか自動検証し、間違っていれば自動修正した上で、
     生成されたExcelの「備考」列に修正した旨を記録します(元データのどこが間違っていたか分かるように)。

2. スクリプトを実行する

   ```bash
   python3 generate_barcode_list.py
   ```

   入力・出力ファイル名を変えたい場合は引数で指定できます。

   ```bash
   python3 generate_barcode_list.py 別の商品リスト.csv 別の出力名.xlsx
   ```

3. `products_with_barcode.xlsx` が生成されるので、Excelで開いて確認・印刷する。

同梱の `products.csv` はサンプルデータです(架空の商品・JANコードです)。
そのまま実行すると同梱の `products_with_barcode.xlsx` と同じものが再生成されます。

## 印刷するときの注意(スキャン精度を落とさないために)

画像方式にしてもプリンタ側の設定で読めなくなることがあるので、印刷時は以下を守ってください。

- **拡大縮小は必ず「100%(実際のサイズ)」で印刷する**(「用紙に合わせて縮小」はOFF)
- **解像度は300dpi以上**
- **黒一色・白い紙に印刷する**(赤などの色付きバーコードはレーザー式スキャナーが読めません)
- **光沢紙は避ける**(反射で読み取りにくくなることがあります)
- 印刷後、バーコードの縦棒がにじんでいたり、くっついていないか目視確認する

## 動作確認について

このツールが出力するバーコードは、`zbarimg`(バーコードデコーダ)で実際に画像から
数値を読み取り直し、CSVに入力したJANコードと一致することを確認済みです
(生成したPNG単体、および完成したxlsxファイルに埋め込まれた画像の両方で検証)。
ただし実機のバーコードスキャナーでの読み取りまでは確認していないため、
まずは数枚だけ印刷してスキャナーで試してから、本番の枚数を印刷することをおすすめします。
