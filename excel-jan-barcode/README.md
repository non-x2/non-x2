# JANコード バーコード付き商品リスト生成ツール

Excelでバーコード付きの商品リストを作ったのにスキャナーで読み取れない、という問題を
解決するためのツールです。商品名とJANコードのCSVから、**本物のバーコード画像**を
貼り付けたExcel(xlsx)を自動生成します。

## なぜ読み取れなかったのか(原因)

「ニコたん」こと [JANCODE-nicotan](https://nicotan.at-ninja.jp/) は、Excelで
`=jan()` 関数を使ってJANコードを専用の文字列に変換し、それに
「JANCODE-nicotan」「JANCODE-nicBAR」などの**専用フォント**を当てて
バーコードの見た目を作るタイプのフリーツールです。この方式は便利な反面、
次の理由でスキャナーが読めなくなることがあります。

- **フォント未埋め込み**: 作った人のPCにしか専用フォントが入っておらず、別のPC
  (印刷担当のPC、印刷後にファイルを開いた別の端末など)で開くと、専用フォントが
  当たらずただの文字列に戻ってしまい、バーコードとして印刷されない。
- **チェックデジット(検査数字)の計算ミス**: JANコードの最後の1桁は決まった計算式で
  出す必要があるが、手入力やコピペでズレると、スキャナーがエラーを出して読み取りを
  拒否する。

このツールは「専用フォントに頼らず、最初から絵(画像)としてバーコードを描いて
Excelに貼る」方式にすることで、上記の問題を構造的に回避しています。どのPCで開いても、
どのプリンタで印刷しても、見た目が変わりません。

## 必要なもの

- Python 3
- 以下のライブラリ(初回のみインストール)

```bash
pip3 install python-barcode openpyxl pillow
```

## 使い方

1. `products.csv` を編集する(商品名とJANコードの2列)

   ```csv
   商品名,JANコード
   剪定バサミ プロ仕様180mm,4901111222236
   培養土 14L(有機配合),450222233334
   使い切り除草剤 お試しミニパック,49012347
   ```

   JANコードは **7桁・8桁(JAN-8/短縮バーコード)・12桁・13桁(JAN-13)** の
   いずれでも入力できます(ニコたんの `=jan()` 関数と同じ桁数に対応)。

   - 桁数が1つ少ない(7桁 or 12桁)場合 → 最後のチェックデジットを自動計算して補完します。
   - フルの桁数(8桁 or 13桁)で入力した場合 → チェックデジットが正しいか自動検証し、
     間違っていれば自動修正した上で、生成されたExcelの「備考」列に修正した旨を
     記録します(元データのどこが間違っていたか分かるように)。
   - Excelの標準の「CSV(コンマ区切り)」形式(Shift-JIS)で保存したファイルも、
     UTF-8のファイルもそのまま読み込めます。

2. スクリプトを実行する

   ```bash
   python3 generate_barcode_list.py
   ```

   入力・出力ファイル名を変えたい場合は引数で指定できます。

   ```bash
   python3 generate_barcode_list.py 別の商品リスト.csv 別の出力名.xlsx
   ```

3. `products_with_barcode.xlsx` が生成されるので、Excelで開いて確認・印刷する。

同梱の `products.csv` はサンプルデータです(架空の商品・JANコードです)。
そのまま実行すると同梱の `products_with_barcode.xlsx` と同じものが再生成されます。

## Excel側で自動的にやっていること

- **見出し行を固定**(スクロールしても1行目が常に見える)
- **オートフィルター**を見出しに設定(商品名やJANコードで並べ替え・絞り込み可能)
- **重複JANコードの自動検出**: 同じJANコードが複数行にある場合、「備考」列と
  実行時のログに警告を出します(コピペミスの早期発見用)
- **印刷設定を「実際のサイズ(100%)」に固定**: Excelの初期設定のままだと
  プリンターの「用紙に合わせて縮小」で意図せずバーコードが縮小され、規格外の
  サイズになって読み取れなくなることがあります。このツールが出力するxlsxは
  最初から拡大縮小100%・印刷範囲設定済みなので、そのまま印刷すれば正しいサイズで
  出力されます。

## 印刷するときの注意(スキャン精度を落とさないために)

上記の通り拡大縮小は自動で100%になっていますが、それ以外は運用でカバーする必要が
あります。

- **黒一色・白い紙に印刷する**(赤などの色付きバーコードはレーザー式スキャナーが読めません)
- **光沢紙は避ける**(反射で読み取りにくくなることがあります)
- **解像度は300dpi以上**(バーコード画像自体は300dpiで生成済み)
- 印刷後、バーコードの縦棒がにじんでいたり、くっついていないか目視確認する

## 動作確認について

このツールが出力するバーコードは、`zbarimg`(バーコードデコーダ)で実際に画像から
数値を読み取り直し、CSVに入力したJANコードと一致することを確認済みです
(生成したPNG単体、および完成したxlsxファイルに埋め込まれた画像の両方、
JAN-13・JAN-8の両方の桁数パターンで検証)。ただし実機のバーコードスキャナーでの
読み取りまでは確認していないため、まずは数枚だけ印刷してスキャナーで試してから、
本番の枚数を印刷することをおすすめします。
