# 🛟 防災情報まとめ（地震・津波・雷・大雨）

気象庁の発表をもとに、**最近の地震・津波の状況・雷注意報・大雨の警報注意報**を
1ページにまとめた防災ページです。台風ページ（`../typhoon-app/`）の弟分で、作りも同じです。

- 公開URL：https://non-x2.github.io/non-x2/bousai-app/
- `index.html` をブラウザで直接開くだけでも使えます（1枚もの・道具のインストール不要）

## 画面の構成（4つのタブ）

| タブ | 出るもの |
|------|---------|
| 🌏 地震 | 最近の地震（新しい順・最大15件）。震度の色分き・M・深さつき |
| 🌊 津波 | いま津波警報・注意報が出ているか＋最近の発表一覧 |
| ⚡ 雷 | 雷注意報が出ている予報区の全国一覧（地方ごと） |
| ☔ 大雨 | 大雨の特別警報・警報・注意報（＋洪水）が出ている予報区の全国一覧 |

## データの取り方（4段構え）

台風ページと同じ「どれかが止まっても必ず何かが表示される」作りです。

1. **ブラウザから気象庁へ直接**（開くたび最新。10分ごと自動で取り直し＋🔄手動ボタン）
2. ダメなら **`data/latest.json`**（GitHub Actions が毎時35分に更新する控え）
3. それもダメなら **端末に残った前回のデータ**（圏外でも出る）
4. 最後は **案内文＋公式リンク**（うその数字は出さない。リンク先で確認してもらう）

※ 地震・津波・雷・大雨は**別々に**切り替わります（地震だけ①、雷は②…もあり得ます）。

## 部品

- `index.html` … ページ本体（タブ・表示・①③④の処理ぜんぶ入り）
- `scripts/fetch_bousai.py` … 気象庁からデータを取って `data/latest.json` を作る係（Python標準機能のみ）
- `data/latest.json` … ②で使う控えデータ（GitHub Actions が自動更新）
- `.github/workflows/bousai-update.yml` … 毎時35分に上のスクリプトを動かす仕掛け

## 安全装置（台風ページの教訓を引き継ぎ）

- **1種類でも取得に失敗したら `latest.json` を書き換えない**（古い情報のほうが、間違った「何もありません」より安全。→ `docs/トラブル解決記録.md` の T12）
- 津波は、自動で判定できないとき**「確認できませんでした」と正直に表示**して公式リンクへ誘導（勝手に「安全」と言わない）
- 発表内容が変わらない回はコミットしない（履歴が無駄に増えない）
