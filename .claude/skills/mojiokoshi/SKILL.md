# 文字起こしスキル（会話をそのまま残す）

## 一言で言うと

**/handoff が「要点だけの付箋」なら、こちらは「録音テープの書き起こし」**です。
Claude Code が自動で残している会話の記録ファイルを `tools/kaiwa_mojiokoshi.py` が読み取って、
発言をそのままの文章で Markdown に変換します。AIが思い出しながら書き直すのではなく
記録ファイルを機械的に変換するので、**抜けや言い換えがなく、トークンもほぼ使いません**。

## 手順

1. **まず実行する**（いまの会話を文字起こしする場合）：
   ```bash
   python3 tools/kaiwa_mojiokoshi.py
   ```
   - `docs/会話ログ/会話ログ_YYYY-MM-DD_HHMM.md` に保存される。
   - 過去の会話を選びたいと言われたら `--list` で一覧を見せて、`--file <パス>` で指定する。
   - 「Claudeが何をしたかも残したい」と言われたら `--tools` を付ける（道具の使用も1行ずつ載る）。

2. **できあがりを軽く見せる**：ファイル名と、冒頭（日付・発言数）＋最初の1〜2発言だけを見せる。
   全文をチャットに貼らない（トークンの無駄づかいになるため）。

3. **⚠️ プッシュ前に必ず確認を取る**：このリポジトリは public（誰でも閲覧可）なので、
   会話ログをプッシュすると**内容がそのまま公開される**。
   - 「この文字起こしをGitHubに保存（プッシュ）すると、会話の内容が公開されます。
     個人情報などが入っていないか確認しました。プッシュしてよいですか？」と聞く。
   - 実際に中身をざっと確認し、住所・電話番号・パスワードらしきものがあれば先に指摘する。
   - **OKが出るまでコミット＆プッシュしない**。クラウドの場合は「プッシュしないとセッション終了で消える」ことも添える。
   - 「手元で読むだけでいい」と言われたら、そのままでよい（コミットしない）。

4. **報告**：✅完了しました＋保存先ファイル名＋発言数を伝える。

## 気をつけること

- 助手（サブエージェント）とのやり取り・Claudeの考え中のメモ・道具の細かい出力は載せない
  （会話の本文だけを残す設計。`--tools` を付けたときだけ道具名が1行ずつ載る）。
- クラウドの会話記録は**その部屋（セッション）が消えると一緒に消える**。
  残したい会話は、その会話の中で文字起こしを頼むのが確実。
- ローカル（デスクトップアプリ）でも同じコマンドで動く（記録の場所・形式が同じため）。
