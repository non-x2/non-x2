# 🚗 交通・ライブカメラ

**公開URL**: https://non-x2.github.io/non-x2/traffic-app/

出発地と目的地を入れると、車のルートを地図に描き、**その通り道にある道路ライブカメラ**を拾い出します。
カメラを押すと、**今の道路の様子**がその場で表示されます（写真は30秒ごとに自動で撮り直し）。

> 「渋滞情報」ではなく「**実際の道路の映像**」で今の状況を見るページです。
> あわせて、全国の高速道路・国道の観測点の「**いまの交通量**」（いつもと比べて車が多いか）も地図に色の丸で出します。
> 渋滞・通行止めの確定情報は、ページ下部の公式サイト（JARTIC など）へのリンクからどうぞ。

---

## 使い方（3ステップ）

1. **出発地**と**目的地**を日本語で入れる（例：「名古屋駅」「静岡市」「東京都千代田区」）
   - 📍 現在地ボタンで、今いる場所を出発地にできます
2. **「🔍 ルートと通り道のカメラを調べる」**を押す
3. 地図の**青い丸**か、下の**カメラ一覧**を押すと映像が出ます

「通り道とみなす幅」は 300m〜3km から選べます。カメラが見つからないときは幅を広げてみてください
（ライブカメラは主に**国道**にあるので、高速道路メインのルートでは少なめです）。

## ファイルの中身

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体。**これ1枚で動きます**（ダブルクリックでも開けます） |
| `data/livecams.json` | カメラ台帳の「大もと」（人が読める形） |
| `scripts/fetch_livecams.py` | カメラ台帳を作りなおす係（Python標準機能のみ） |
| `data/road_status.json` | 🚦 交通量の控え（毎時、自動更新） |
| `data/road_points.json` | 🚦 交通量の観測点台帳（場所・市区町村名） |
| `scripts/fetch_road_status.py` | 交通量を取ってくる係（Python標準機能のみ） |

台帳は `index.html` の中にも埋め込まれています。
これは**ダブルクリックで開いたとき**（`file://`）でも動くようにするためです
（`file://` では別ファイルの読み込みがブラウザに止められるため）。
`data/livecams.json` と埋め込みは、上のスクリプトが**同時に**書き換えるのでズレません。

---

## 台帳の作りなおし方

```bash
python3 traffic-app/scripts/fetch_livecams.py
```

やっていること:

1. 全国の道路ライブカメラの位置データを取得
   （[国土技術研究センター「道路チェック地図」](https://www.jice.or.jp/knowledge/maps/roads)）
2. 説明文から「写真のURL・カメラのページ・管理者名」を取り出す
3. **写真URLが `https://` で開けるか1台ずつ実際に試す**（→ 後述）
4. 緯度経度から市区町村名を調べる（[国土地理院](https://maps.gsi.go.jp/)。前に調べたぶんは使い回し）
5. `data/livecams.json` と `index.html` の台帳を書き換える

急いでいるときは `--no-verify`（写真の確認をとばす）／`--no-geocode`（市区町村の調べ直しをとばす）が使えます。

**⚙️ 自動更新**: `.github/workflows/livecam-update.yml` が**毎週火曜 5:10（日本時間）**に上を実行します。
カメラは増減したり故障したりするので、週1で見直す形にしています。

## 🔑 いちばん大事な仕組み：「https で開ける写真だけ出す」

全国のカメラの写真URLは、**すべて `http://`（暗号化なし）** で公開されています。
一方このページは `https://` で公開されているため、`http://` の写真をそのまま出そうとすると
ブラウザが**問答無用でブロック**します（「混在コンテンツ」という安全のしくみ）。

そこで台帳を作るときに、`http://` を `https://` に読み替えて**1台ずつ実際に開いてみて**、
ちゃんと画像が返ってくるものだけ「このページで見られるカメラ」として記録しています。

現在の内訳（2026-08-14 時点）:

| | 台数 |
|---|---|
| 全国のカメラ | **1,430台** |
| └ ページ内で映像が見られる | **1,038台** |
| └ 公式ページを開いて見る | 392台 |

映像を出せないカメラも、一覧には**灰色の丸**で出て、押すと**公式ページへのリンク**が出ます
（＝「カメラがあるのに存在ごと消える」ことがないように）。

## 🚦 いまの交通量（いつもと比べて多い？）

全国の高速道路・一般国道にある**常時観測点（約1,000か所）**が数えた「5分間に通った車の台数」を、
**1週間前の同じ時刻とくらべて**色分けし、地図に小さな丸で重ねます
（🔴かなり多い／🟠多い／🟢いつも並み／🔵少ない／⚪比べられない）。

データの流れ（台風・防災ページと同じ「控え」方式）:

1. `.github/workflows/traffic-update.yml` が**毎時45分**に国土交通省の「交通量API」から取得
   → `data/road_status.json` に控えを保存（**取得に失敗した回は書き換えない**安全装置つき）
2. ページはその控えを読む（開いている間は5分ごとに読み直し）
3. 控えが読めないときは、端末に残った前回分 → それも無ければ正直に案内文

正直な注意書き:

- **「渋滞かどうか」は分かりません**。国のデータに速度が入っていないため、
  出せるのは「台数がいつもより多いか」まで。うそをつかない範囲でこの見せ方にしています。
- 観測から**約20分遅れ**で届きます。控えは毎時更新なので、表示は最大1時間半ほど前の状態です
  （観測時刻をいつも画面に出しています）。
- 「いつも」＝1週間前の同じ時刻なので、**連休や悪天候の週はくらべる相手のほうがズレます**。
- API はブラウザから直接呼べない決まり（CORS未対応）のため、GitHub Actions 経由の控え方式にしています。

出典：**国土交通省API機能による交通量(参考値)を加工して作成**
（[交通量オープンデータのポータル](https://www.jartic-open-traffic.org/)。無料・登録不要・出典明記が条件）

## つくりの特徴

- **外部ライブラリを一切使いません**（地図も自前で描いています）。のんラボの他のページと同じく、1枚のHTMLで完結します。
- **鍵（APIキー）が要りません**。使っているのは、無料で鍵不要の公開サービスだけです。

| 役割 | 使っているもの |
|---|---|
| 地図 | [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)（国土地理院） |
| 地名 → 緯度経度 | 国土地理院 住所検索 |
| 緯度経度 → 市区町村 | 国土地理院 逆ジオコーダ（台帳を作るときだけ） |
| 車のルート検索 | [OSRM](https://project-osrm.org/)（[OpenStreetMap](https://www.openstreetmap.org/copyright) のデータ） |
| カメラの位置 | 国土技術研究センター「道路チェック地図」 |
| カメラの映像 | 各道路管理者（国土交通省 各地方整備局ほか） |
| いまの交通量 | 交通量API（国土交通省）※GitHub Actions経由で毎時取得 |

## ⚠️ 正直に書いておくこと

- **所要時間は渋滞を考えていません**。OSRM が出す「道のりから計算した目安」です。
- **交通量の色は渋滞判定ではありません**（台数がいつもより多いかどうかだけ。詳しくは上の🚦の章）。
- **ルート検索は OSRM の公開サーバー**を使っています。無料で親切に開放されているものなので、
  混んでいる時間は遅かったり、応答が返らないことがあります（そのときはエラーを正直に出します）。
- **カメラの映像は各管理者のサーバーから直接**取得します。点検中・故障中は映像が出ないことがあります
  （そのときは「読み込めませんでした」と表示し、公式ページへ案内します）。
- 運転中の操作は危険です。**出発前か、停車中に**見てください。
