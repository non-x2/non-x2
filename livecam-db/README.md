# 📷 ライブカメラ台帳（livecam-db）

日本全国のライブカメラを **1か所にまとめた「台帳（データベース）」** です。
のんラボのどのページからでも、ここを読めば同じカメラ情報が使えます。

> 🔑 **このフォルダが「大もと」です。**
> 各アプリ（`traffic-app/` など）が持っているカメラ情報は、ここから配ったコピーです。
> 直したいときは、アプリ側ではなく**ここを作りなおして配りなおして**ください。
> （`data/offices.json` と同じ「正しい情報は1か所だけ」の考え方です）

---

## いま入っているカメラ

`python3 livecam-db/livecam.py info` でいつでも確認できます（2026-08-15 時点：**3,424台**／うち
**2,615台**はページ内に映像を出せる／一般道1,331・高速81・河川1,819・ダム114・海79）。

| 情報源 | 中身 | 利用条件 |
|---|---|---|
| 国土技術研究センター（JICE）道路チェック地図 | 国土交通省 各地方整備局ほかの**道路**ライブカメラ | 国が公開している地図データ |
| 国土技術研究センター（JICE）河川チェック地図 | 同じく**河川・ダム**のライブカメラ | 同上 |
| 海上保安庁 ライブカメラ | 灯台・港・岬の**海**のライブカメラ | **公共データ利用規約（PDL1.0）**＝出典を書けば再利用可 |

種類（`cat`）は `road`（一般道）／`expressway`（高速・自動車専用道路）／`river`（河川）／
`dam`（ダム）／`weir`（堰・水門）／`sea`（海）に分かれています。

> 🛣 **高速道路について**：`expressway` は**国が管理する**高速道路・自動車専用道路です
> （三陸道・京奈和自動車道・北近畿豊岡自動車道・名阪国道など **81台**）。
> **NEXCO・首都高・阪神高速などが管理する高速道路のカメラは入っていません**——
> 各社の利用規約で他サイトへの転載が認められていないためです（下の「取り込まなかった情報源」を参照）。
> 名前で見分けているため、「◯◯道路」で終わる路線（自動車専用道路のこともある）は `road` のままです。

> 📄 **出典の記載について**：海上保安庁のデータは PDL1.0 の条件として出典の記載が必要です。
> 台帳の `sources` 欄に出典を記録し、各カメラの `owner` にも「海上保安庁 ◯◯海上保安部」と入れています。

## 使い方

### コマンドで調べる

```bash
python3 livecam-db/livecam.py info                                        # 台帳の要約
python3 livecam-db/livecam.py near 35.681 139.767 --radius 10000          # 東京駅の近く（6台）
python3 livecam-db/livecam.py near 34.70 137.73 --radius 10000 --category river  # 河川だけ（10台）
python3 livecam-db/livecam.py search 国道1号 --pref 静岡県                 # 名前・場所・管理者で探す
python3 livecam-db/livecam.py route 40.81,140.45 40.83,140.73                # ルート沿い（五所川原→青森・3台）
python3 livecam-db/livecam.py search 天竜川 --with-image --json           # JSONで受け取る
```

### プログラムから使う（他のプロジェクトでも同じ）

```python
import sys; sys.path.insert(0, "livecam-db")
import livecam

db = livecam.load()

# ① ある地点の近くのカメラ（近い順）
for cam in livecam.near(db, 35.681, 139.767, radius_m=10000, limit=5):
    print(cam["name"], cam["place"], round(cam["distance_m"]), "m")

# ② ルート沿いのカメラ（出発地からの順）  route = [[緯度, 経度], …]
for cam in livecam.along_route(db, route, radius_m=1500):
    print(cam["name"], "出発から", round(cam["along_m"] / 1000, 1), "km")

# ③ しぼり込み
rivers = livecam.filter_cams(db, category="river", pref="新潟県", with_image=True)
```

## カメラ1台の形（スキーマ）

```json
{
  "id":    "jice-roads-00042",
  "src":   "jice-roads",
  "cat":   "road",
  "name":  "国道1号",
  "place": "静岡県静岡市清水区",
  "lat":   35.012345,
  "lon":   138.123456,
  "img":   "https://…/cam.jpg",
  "page":  "https://…",
  "owner": "中部地方整備局 静岡国道事務所"
}
```

| 項目 | 意味 |
|---|---|
| `id` | 台帳の中での通し番号 |
| `src` | どの情報源から来たか |
| `cat` | 種類（road / expressway / river / dam / weir / sea） |
| `name` | 路線名・河川名など |
| `place` | 市区町村（緯度経度から自動で付けています）。**5台だけ空**＝海上や山間部で、国土地理院の区域データに当たらない地点 |
| `lat` / `lon` | 緯度・経度 |
| `img` | **ページ内にそのまま出せる写真URL**。出せないカメラは `null` |
| `page` | 公式のカメラページ |
| `owner` | 管理者（◯◯地方整備局 など） |
| `also` | 別の情報源にも載っていた場合、その情報源（**無いカメラが大半**。`cam.get("also", [])` で読むこと） |

---

## 🔑 いちばん大事な仕組み：「https で開ける写真だけ `img` に入れる」

全国のライブカメラの写真URLは、**ほとんどが `http://`（暗号化なし）** で公開されています。
一方、のんラボの公開ページは `https://` なので、`http://` の写真をそのまま出そうとすると
ブラウザが**問答無用でブロック**します（「混在コンテンツ」という安全のしくみ）。

そこで台帳を作るときに、`http://` を `https://` に読み替えて
**1台ずつ実際に開いてみて**、ちゃんと画像が返るものだけ `img` に入れています。

開けなかったカメラも**消しません**。`img` を `null` にして `page`（公式ページ）を残すので、
アプリ側は「ここにカメラはあるけれど、映像は公式ページで見てください」と案内できます。

## 台帳の作りなおし方

```bash
python3 livecam-db/build.py      # 集める → 重複をまとめる → 写真を確認 → 市区町村を付ける
python3 livecam-db/export.py     # 各アプリに配る（traffic-app など）
```

写真の確認は3,000台以上に1台ずつアクセスするので**15〜20分**かかります。急ぐときは:

```bash
python3 livecam-db/build.py --no-verify     # 写真の確認をとばす（前回の結果を使う）
python3 livecam-db/build.py --no-geocode    # 市区町村の調べ直しをとばす
python3 livecam-db/build.py --only jice-roads   # 情報源をしぼる
```

**⚙️ 自動更新**：`.github/workflows/livecam-update.yml` が**毎週火曜 5:10（日本時間）**に
上の2つを実行します。カメラは増えたり減ったり故障したりするので、週1で見直す形にしています。

### 安全装置

- 取得に失敗したら、**今ある台帳は上書きしません**
- カメラが極端に少ない結果になったときも上書きしません（こわれたデータで壊さないため）
- **情報源ごと**に前回の70%を下回ったら中止します
  （合計だけ見ていると「道路が全部消えても河川が残っているから合格」になってしまうため）
- 通信の失敗は**カメラ1台ぶんの失敗として扱い**、全体を止めません
  （1台の不調で週1の更新が丸ごと止まらないように）
- 同じ座標に3種類以上の名前が登録されていたら**警告を出します**
  （元データのまちがいに気づくため。実際に北海道の8河川が同じ1点に登録されている例があります）

## 新しい情報源の足し方

1. `sources/` に1ファイル追加して、`collect_all()` を用意する
   （返り値は「カメラ一覧」と「情報源の記録」の2つ）
2. カメラ1台の形は上のスキーマにそろえる（`img` は http のままでOK。確認は `build.py` がやります）
3. `build.py` の `COLLECTORS` に登録する

### 📋 調べたけれど取り込まなかった情報源（2026-08-15 時点）

「もっとカメラを増やせないか」を調べた結果の記録です。**同じ調査を繰り返さないため**に残しています。

#### ❌ 取り込まない：再利用の禁止が明記されているもの

| 情報源 | 件数 | 明記されている内容 |
|---|---|---|
| 福井県 みち情報ネットふくい | 約220 | 「当ホームページに掲載されている内容の**無断転載を禁じます**」 |
| 群馬県 ぐんまの道路ライブカメラ | 130 | 「著作権法上認められた場合を除き**無断転載を禁じます**」 |
| 青森県 青森みち情報 | 多数 | 「**無断で転用・引用することはできません**」 |
| 民間のライブカメラまとめサイト | 3万件超 | 明記は無いが、**人手で整理された名簿そのものが商品**。日本の著作権法では、選び方や並べ方に工夫のあるデータベースにも権利が生じえます |
| **NEXCO東日本（ドラぷら）** | 多数 | 利用規約に「**他のサイトや印刷媒体に転載したり、商用目的として利用することはできません**」と明記。NEXCO中日本・西日本、首都高、阪神高速なども同様の民間企業サイト |

→ **リンクで案内する**方針にしました（`traffic-app` の「各県の道路カメラサイト」欄）。
   どうしても台帳に入れたい場合は、**各担当課に一報して許可を得てから**足してください。

#### ⏸ 保留：明記が無いもの

| 情報源 | 件数 | 状況 |
|---|---|---|
| 富山県 道路情報 | 174 | JSON・緯度経度・https画像がそろっていて技術的には理想的。ただし利用条件の記載が見つからず、**「書いていない＝使ってよい」ではない**ため保留 |

#### 🚫 条件に合わなかったもの

| 情報源 | 理由 |
|---|---|
| 国土交通省 水防災オープンデータ提供サービス（CCTV約3,000＋簡易カメラ約4,000） | **有償**（実費相当額）。※ JICE の2つの地図データは、これを国が無料で配っている経路とみられます |
| 国土交通省 道路情報提供システム（全国の地方整備局共通） | 全国規模になりうるが、**防御装置に阻まれて到達できず**（日本国内からなら取れる可能性あり） |
| 栃木県 河川ライブカメラ（CC BY 4.0） | ライセンスは問題なし。ただし画像の配信元が**海外からのアクセスを遮断**しており、GitHub Actions から取得できない見込み |
| 島根県・石川県・岐阜県・長野県・秋田県・福島県・鳥取県・新潟県 | 機械で読める一括データが見つからず（HTMLのみ／SPAの内部APIを特定できず） |
| 京丹後市（CC BY 4.0・8件）／北九州市（CC BY・6件） | ライセンスは問題なし。**規模が小さい**ため今回は見送り。増やしたくなったら足せます |

### 情報源を選ぶときの約束 🚧

- **公的機関または公的性格の団体が公開しているもの**を使う
  （国土交通省・各地方整備局・自治体・独立行政法人など）
- **民間のまとめサイトの一覧を、まるごと写して使わない**。
  他人が時間をかけて集めた名簿そのものには権利が生じうるため
  （日本の著作権法でも、選び方や並べ方に工夫のあるデータベースは保護されえます）。
  カメラの映像そのものは各管理者のものを直接見に行くのが筋です。
- 相手のサーバーに負担をかけない（同時アクセス数は控えめに、更新は週1程度に）

## ファイルの中身

| ファイル | 役割 |
|---|---|
| `build.py` | 台帳を作る司令塔（集める→まとめる→確認→保存） |
| `export.py` | 台帳を各アプリに配る係 |
| `livecam.py` | 台帳を**使う**ための小さな道具（近くを探す・ルート沿いを探す・検索） |
| `sources/base.py` | どの情報源でも使う共通の道具（取得・https確認・市区町村） |
| `sources/jice.py` | 情報源①：JICE の道路／河川ライブカメラ |
| `sources/kaiho.py` | 情報源②：海上保安庁のライブカメラ（灯台・港・岬） |
| `data/livecams.json` | できあがった台帳（**大もと**） |

すべて **Python 3 の標準機能のみ**で動きます（追加インストール不要）。
